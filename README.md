# ChinaUV
Code for Urban villages in china
<br>Data link:  http://doi.org/10.57760/sciencedb.28387
The code in this repository implements the "ChinaUV++: a national map for China's urban villages with rooftops and population derived from VHR satellite imagery in 2020".
Citation：Shiying Yuan, Quanlong Feng, Bowen Niu, et al. ChinaUV++: a national map for China’s urban villages with rooftops and population derived from VHR satellite imagery in 2020[DS/OL]. V2. Science Data Bank, 2026[2026-05-05]. https://doi.org/10.57760/sciencedb.28387. DOI:10.57760/sciencedb.28387.
